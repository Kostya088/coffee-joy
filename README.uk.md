## ☕ Про проєкт

Вебсайт присвячений любителям кави, надаючи платформу для дослідження та
вивчення кави.

## 🛠 Технології

- **Основні:** HTML5, CSS3, JavaScript (ES6+)
- **Збірка:** [Vite](https://vitejs.dev/)

## 🚀 Встановлення та запуск

### Попередні вимоги

- Встановлений [Node.js](https://nodejs.org/) (версія 14 або новіша)

### Кроки

1. **Клонувати репозиторій:** git clone
2. **Встановити залежності (NPM):** npm install
3. **Запустити проєкт у режимі розробки:** npm run dev
4. **Відкрити посилання, яке з'явиться у терміналі** (зазвичай
   http://localhost:5173/)
