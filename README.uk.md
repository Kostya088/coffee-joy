## ☕ Про проєкт

Вебсайт присвячений любителям кави, надаючи платформу для дослідження та
вивчення кави.

## 🛠 Технології

- **Основні:** HTML5, CSS3, JavaScript (ES6+)
- **Збірка:** [Vite](https://vitejs.dev/)

## 🚀 Встановлення та запуск

### Попередні вимоги

- Встановлений [Node.js](https://nodejs.org/) (версія 14 або новіша)

### Кроки

1. **Клонувати репозиторій:** git clone https://github.com/Kostya088/coffee-joy.git
2. **Перейти до директорії проєкту:** cd coffee-joy
3. **Встановити залежності (NPM):** npm install
4. **Запустити проєкт у режимі розробки:** npm run dev
5. **Відкрити посилання, яке з'явиться у терміналі** (зазвичай
   http://localhost:5173/)
